# GitHub 品牌素材

`social-preview.png` 用于仓库社交预览与 README。图标直接复用品牌源文件，不修改应用角色或个人头像。

封面源文件为 `social-preview.html`，画布 1280 × 640。使用本地 HTTP 服务打开，等待字体与图标加载后以该视口导出 PNG；GitHub 上传文件须小于 1 MB。

字体为 [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope)，随附 [SIL Open Font License](./fonts/OFL.txt)。颜色沿用 [Hanppie 设计规范](../../../../DESIGN.md)，角色来源见[品牌清单](../manifest.json)。
