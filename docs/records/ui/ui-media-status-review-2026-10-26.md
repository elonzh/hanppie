# 媒体与机器人状态体验评审 · 2026-10-26

> [文档导航](../../README.md) / [历史与验证记录](../README.md)

## 范围与结论

本次围绕媒体浏览、机器人状态，以及设置中的同类反馈模式做源码与桌面验收。检查了导航、设置分类与详情、SD/本地列表、照片预览和视频播放；没有把一次桌面检查表述为全平台、全部设备或全应用零缺陷认证。长期规则见 [DESIGN.md](../../../DESIGN.md#布局与自适应)，当前实现见 [架构文档](../../architecture/hanppie.md)。

## 发现与处理

| 优先级 | 根因与影响 | 处理 |
| --- | --- | --- |
| P1 | 组件在线状态与版本分成两个展开列表，同一对象被迫来回比对 | 按组件合并；一组内展示状态、告警和一个或多个版本，基本信息保持上方紧凑分列 |
| P1 | 缩略图由选择动作触发，并占用页面忙碌状态 | 可见文件自动预取；选择独立于请求，缩略图状态独立于刷新/下载，浏览不锁定 |
| P1 | 本地列表一直传入空缩略图 | 可见照片与视频生成有界缩略图，独立于机器人连接；缓存不保存整张照片 |
| P2 | 加载/错误文字挤在媒体标题下，反馈作用范围错误 | 每张缩略图在固定图片位置显示动画；传输进度属于文件任务；临时错误浮动提示，首次列表失败在列表区域重试 |
| P2 | 下载时禁止选择，放开选择又可能隐藏取消入口 | 允许继续浏览，页面底部保留正在下载的文件、进度与取消入口；相机传输串行，已开始的预览完成后让出 |
| P2 | 状态页混入电池原始值、十六进制编号、报告年龄 | 普通状态页保留电量与可理解的警告，原始数据仍在数据/诊断层 |
| P2 | 缩略图就绪后失去照片/录像的视觉区别；本地空详情提示“下载” | 录像缩略图叠加小播放标记；空详情改为通用预览提示 |
| P2 | 配置成功段落长期堆在运动、外接照明、存储页 | 已有值能够体现结果时不重复堆成功文字；格式化请求确认改为 toast，实际存储状态继续由设备推送决定 |

本轮没有增加依赖、下载全部媒体的后台扫描、定时版本轮询或新协议兜底。统一缓存和调度保留在共享控制器；平台代码仅提供视频首帧解码。

## 桌面与设备证据

- 65 项相关桌面测试全部通过，桌面应用打包成功；录像标记补齐后仅复测受影响的 4 项媒体用例并重新打包。自动化覆盖照片与真实合成 MP4 的自动列表预览、NV16 预览、网络失败与重试、下载优先与取消、断线/重绑、列表滚动、预览尺寸、合并组件、加载与选中布局。测试使用临时目录，没有删除用户媒体。
- 横屏覆盖 844×390、1024×600、1280×720，中英文、深色主题和 1.4 倍字体；截图保存在 `shared/build/reports/ui/`。首次批量检查后集中修正文案、录像标记与同类成功反馈，之后做确认。
- 最新桌面包通过 Codex 原生应用工具连接当前机器人。首次进入本地媒体，现有 JPEG 和 MP4 自动出现缩略图；进入 SD 卡不选择文件，首屏 6 项自动出现预览，滚动后其余 4 项也出现，总计 10 项。标题下无缩略图文字，详情仍为空选择状态。
- 机器人状态自动读到型号、激活和主固件；展开同一个组件列表可同时看到在线状态及相机、底盘、电池、云台等版本。部分电机版本查询未成功，显示版本暂不可用；没有把这当作模块离线。
- 验收只读取状态和媒体，未移动、发射、拍摄、格式化或删除 SD 文件；测试应用关闭并释放连接。真实画面只在验收工具中查看，未放进仓库。

## SD 删除调查

结论是**暂未确认可安全实现的 RoboMaster 单文件删除协议**，没有新增假删除按钮。官方本地删除调用、原生符号、通用文件传输 DEL 枚举及其缺失的请求/回执定义，统一记录在[协议文档](../../architecture/robomaster.md#相册索引与媒体传输)。没有发送猜测的 DEL 请求，也没有用 FTP 目录或整卡格式化替代。未来需要确认设备端删除请求结构、文件身份和成功回执，再用专门的可丢弃媒体验收。

## 验证边界

桌面测试和真实只读浏览分别是独立证据。Android 未构建、未启动模拟器；新增 iOS/Android 视频缩略图实现尚未编译和运行验证。没有实机单文件删除或格式化验收。
