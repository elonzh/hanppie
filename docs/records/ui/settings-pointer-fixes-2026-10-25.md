# 设置与鼠标云台修复验收（2026-10-25）

> [文档导航](../../README.md) / [历史与验证记录](../README.md)

> 后续范围变更：用户反馈鼠标移动卡顿并要求删除该功能，鼠标修复方案已由[完整移除](#鼠标云台移除)取代。下文原验收结果保留为历史记录，不代表当前产品仍支持鼠标云台。

基线为 `c60ed1c`。本轮处理鼠标稍动即退出、设置页信息与操作混排，以及不适用的头灯读取入口。当前实现职责和用法以[架构说明](../../architecture/hanppie.md)与中英文 README 为准，本文件只记录本次证据。

## 鼠标捕获

旧适配器每次回中都会进入等待状态，要求精确的中心事件或中心坐标采样；持续移动时，事件合并或指针已经再次移动都可能让该条件不成立，并在 250 ms 后结束捕获。中心坐标分支还会误吞同坐标的左右键按下和释放。

macOS 改用 `CGWarpMouseCursorPosition` 回中，只在最初获取捕获时确认中心；持续输入不依赖每次回中的合成事件。中心过滤只作用于移动与拖动事件。其他桌面宿主仍用 AWT 光标移动；共享层的灵敏度、角速度限制、控制代次、驾驶 ticker、失焦与 Esc 释放规则不变。

Apple 明确说明该 API 移动光标而不发布输入事件，适用于回中用途，见 [CGWarpMouseCursorPosition](https://developer.apple.com/documentation/coregraphics/cgwarpmousecursorposition(_:))。这不构成实体鼠标手感或机器人物理动作的证明。

原生 macOS 验收复用已授权的 HanppiePointerQA，使用真实 `RemotePage`、真实捕获适配器和内存机器人：

- 首次 AX 点击时窗口未激活，捕获被准入检查拒绝；激活窗口后重新开启成功。
- 三次 CUA 拖动产生 34 条实际位移回调，捕获未因连续输入退出，失联计数为 0。
- 内存会话记录 21 次非零云台输入，底盘三个分量始终为零，云台分量不超过既有限制 90°/s。
- CUA 拖动的左键产生 3 次内存红外调用，水弹为 0；真实设备连接和 HTTP 请求均为 0。
- Esc 释放后输入和最后驾驶值均归零，光标样式与原位置恢复。QA 模型关闭、临时目录删除，进程退出。

AWT 回归还覆盖超过原 250 ms 窗口的连续事件、始终偏离中心的坐标采样、中心坐标按键、拖动及释放后不再接收旧事件。该测试需要真实窗口焦点；无图形桌面或无法取得焦点时条件跳过。

## 设置页

- 分类导航保留，宽窗口使用侧栏，紧凑或大字横屏逐页返回；详情宽度有界。
- 机器人维护改为任务目录。状态、信息、存储、电源和条件 SDR 各自进入详情；编址、校准、固件、机械臂和扩展继续进入既有功能页。
- 电池原始值按需展开；目录不展示格式化、关机、重启等执行控件。危险操作继续使用原有确认与准入检查。
- 音视频页保留应用偏好，相机和音频的设备操作进入子页；控制页将机内运动参数独立呈现。
- 选择器采用 Miuix 设置行，导航使用箭头行，设备错误在所属任务内呈现。反馈合并完整辅助功能文本，保存成功短时显示后清除。
- 从设备告警直达状态页仍有效，恢复普通设置入口时清除旧子页。退出子页不会将设备操作误当作应用偏好保存。

桌面测试覆盖 844×390、1024×600、1280×720、中英文以及 1.4 倍字体，检查入口、返回、表单、禁用语义、错误恢复和危险操作确认；生成的共享截图使用内存设备数据。完成一轮批量检查和一轮确认，修复复选框贴边及存储页重复标题。

打包后的实际 macOS App 另经 CUA 检查维护目录和外接照明页面：连接真实机器人，页面任务分组与返回层级正常；照明拒绝显示为当前连接配置不可用，原先的笼统重试提示及写入控件不再出现。验收过程中未进入驾驶舱、Lab、拍录或设备维护动作；退出确认完成后进程退出。

## 外接照明与实机复核

官方二进制的头灯读写映射到六路 PWM，界面节点初始隐藏。原生数组的左右通道下标不能当作已验证的物理接口编号；当前文案只说明 PWM 照明配件，与机身装甲状态灯分开。原生证据见[头灯亮度调查](../../architecture/robomaster.md#头灯亮度)。

普通画面设置移除头灯读取，在“机器人维护 → 外接照明”中按需读取。只有成功取得亮度才开放编辑；实机已复现的读取拒绝码 `2` 记为当前连接不可用，不自动重试或按型号永久屏蔽；其他拒绝和超时保留原有恢复路径。连接替换清除该状态，准星配置不受影响。

用户重新充电开机后，重新监听广播发现一台机器人；只读宿主确认电量 93%、轮速停稳，照明读取仍返回 `REJECTED / 2`。宿主没有进入遥控，照明写入、非零运动和发射均为零，连接已关闭。随后实际桌面 App 重现同一不可用反馈，退出前界面电量 86%。未写 PWM、网络、固件、编址或校准。

## 鼠标云台移除

用户明确要求删除鼠标云台。已删除驾驶舱入口、灵敏度与反向设置、中英文提示、桌面 AWT 捕获与 macOS 权限查询，以及不再使用的 JNA 直接依赖。共享输入状态只保留陀螺仪启停；原鼠标左右键的发射/变焦回调与捕获遮罩同时删除。旧偏好沿既有未知字段策略读取，无迁移或兼容层。键盘、屏幕摇杆、发射按钮、倍率入口及陀螺仪输入保留；设置页整理和外接照明处理保留。

移除后的 42 项定向测试全部通过，无失败、错误或跳过：共享陀螺仪契约 6、驾驶舱 UI 4、可调控件 UI 4、既有输入响应 1、发射回归 11、设置往返 10、本地化 6。最终补充无传感器终端的界面检查并更新指南后，4 项驾驶舱 UI 与 6 项本地化复核再次通过，不累计重复用例。中英文四组横屏覆盖 844×390、1024×768、1280×720 和 1.4 倍字体；实际共享渲染确认鼠标入口与设置消失，有传感器时陀螺仪可启停，无传感器时不留空入口，键盘云台及双摇杆保留。旧鼠标偏好读取后保留陀螺仪和其他设置，后续保存不再写鼠标字段。

最终 `:desktopApp:classes` 与 `:desktopApp:createDistributable` 通过，包内共享模块逐条目与当前构建一致，已无捕获适配器、权限异常或旧输入模式类。原始日志、最终 XML、截图和身份记录位于忽略目录 `.hanppie/validation/2026-10-25-remove-mouse-gimbal/`。Android 未构建或验证，本轮未连接机器人。
