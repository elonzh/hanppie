# 设置与媒体体验验证（2026-10-25）

> [文档导航](../../README.md) / [历史与验证记录](../README.md)

本轮处理用户提出的五项问题：设置状态依赖手动查询、驾驶舱音视频按钮点击无效、临时反馈挤占页面、日常路径暴露技术信息，以及本机拍摄未纳入媒体库。当前职责与用法统一见[架构说明](../../architecture/hanppie.md)和中英文 README，本文件记录本轮证据与边界。

## 验证路径

- 真实设置页进入设备信息后自动读取全部适用版本与激活；只对失败项提供重试，取消与连接替换仍隔离旧请求。电源与 SDR 自动读取，固件只自动查询配置；重连所得的 SDR 确认快照不因页面初始化而丢失。
- 场景进入与返回测试使用坐标触控验证四个媒体按钮，覆盖视频停止后的重新开启和恢复前台；没有用语义点击绕过原先兄弟图层遮挡的问题。缓存旧帧不能放开机械输入。
- 桌面 `RobotVideo` 使用实际随包 FFmpeg 与合成 H.264，验证视频停止/恢复、拍照、录像结束封装和本地媒体索引；机器人/网络入口使用内存替身，驾驶值始终为零。
- 应用管理目录中的 JPEG/MP4 可在离线媒体库选取、预览、播放、暂停、重播及删除；另核对已有下载文件的预览归属、坏文件反馈与导出路径。文件播放测试实际解码合成录像的视频和音轨，不向系统扬声器输出测试音。
- 共享设置保存提示浮在表单上方，不改变表单位置；超时清除，需要用户处理的保存错误仍留在任务内。页面不展示保存绝对路径、音频解码字节数或 DataStore 名称。

中英文界面覆盖 844×390、1024×600、1280×720 与 1.4 倍字体。首轮画面检查发现紧凑大字录像按钮被正文裁切，已将画面与播放控制改为有界区域，导出和删除固定在详情底部；确认轮核对播放按钮可见、无重复外部播放器入口。内存夹具、合成文件和真实平台解码分别记录，不作为真实机器人媒体或声音听感的证明。

## 最终结果与边界

影响面验证覆盖 57 项：56 项通过，1 项暴露 SDR 重连后确认状态被页面刷新覆盖。修正后，SDR 界面与控制器 3 项复核通过；清理旧媒体 HUD 注入后，最终场景进入/返回与新旧帧准入 3 项复核通过。同轮媒体拍录、浮动提示及本地化复核通过，不累计重复执行次数。所有本轮发现的失败均已修正或在对应测试中完成复核。

`:desktopApp:classes`、`:desktopApp:createDistributable` 与 `:shared:compileKotlinIosSimulatorArm64` 通过。最终桌面包内共享模块的 1,702 个条目与当前构建逐条一致；中英文资源各 1,724 项，资源键无重复。没有遗留测试工作进程或 FFmpeg 子进程。iOS 只验证接口编译；Android 没有构建、模拟器、UI 或实机验证。本轮没有连接机器人、运动、发射、更新固件、格式化或写入设备配置。真实收音、实体按键/读屏、多屏与移动端运行仍待验。

原始日志、XML、共享渲染截图和包身份位于忽略目录 `.hanppie/validation/2026-10-25-settings-media/`；临时拍摄和播放样本使用测试临时目录，系统已有拍摄文件只在产品的正常媒体索引中发现，测试不读取或删除这些文件。既有设置整理、外接照明与鼠标移除保留；没有提交或推送代码。
