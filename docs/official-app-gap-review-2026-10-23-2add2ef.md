# 官方 App 差距复核 · 2026-10-23 · 2add2ef

## 结论与基线

Hanppie 已覆盖已就绪机器人的日常连接、驾驶、音视频、机载 Python 创作，以及多项维护配置的桌面离线流程；**仍缺完整的编址、校准、固件维护、扩展模块控制、视觉交互、程序安装/技能、自定义 UI、输入设备与玩法体系**。已经写出的协议、收到请求应答和实际设备动作属于不同完成层级。

本报告固定对照提交 `2add2ef04a715385c2d41b6c7eae03ffb018128a`，另检查工作区未提交的 M01 编址协议基础。当前实施台账的 35 个任务包中，15 个离线完成、1 个实施中、19 个待实施；另有 C01–C14 共 14 项冲突保持现状。任务包大小不同，这些数值不能换算为官方功能覆盖率。**新增能力的实机验收均未执行。**

这是一次日期化调查快照。[实施台账](./official-app-capability-implementation.md)维护后续进度、冲突、提交及待验状态；[应用架构](./architecture.md)维护当前实现；[原生架构](./architecture-robomaster.md)维护上游协议事实。本报告不替代这些权威来源，也不改写此前的调查快照。

官方二进制基线为本机保存的 **macOS RoboMaster 1.1.5 / build 239**，已重新读取安装包 `Info.plist`。覆盖 C# 工作流、RobotService 的 key/参数和原生 `unitybridge`，不能据此声称覆盖各端最新 App。此次访问官方 App 入口发生重定向/访问失败，未取得足以确认各平台当前最新版本的证据；没有安装或运行新版官方客户端。

75 项之外的设备配置必须单独评估：音量/语音、变焦、抗闪烁/时间、SD 状态/格式、AP/信道/条件 SDR、编程节能现已具备多项离线闭环；编址、校准、固件、机械臂/爪、扩展订阅、GamePad、准星落点和裁判参数仍有上述差距。设备设置不会因为“恢复应用默认设置”而自动加入重置范围，见 C10。

裁判表还涉及 Mode、Gun、Time、MaxHP、Hit、ShootingFrequency、过热/冷却、IR/装甲/血量开关、MaxSpeed，以及技能 ID/CD、增益、复活和结算参数。这些不在 75 项默认偏好中；固定的 `3f:09` 初始化仅发送一组参数，尚不是用户可编辑、可同步、可恢复的玩法配置系统。内部字段也不应全部暴露成设置。
