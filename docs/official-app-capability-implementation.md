# 官方 App 能力补齐实施台账

## 目标与范围

依据[2026-10-22 差距调查](./official-app-gap-analysis-2026-10-22.md)，逐个完成能力、离线验证并分别提交。调查附表是固定版本的证据快照；本文件维护实施范围、进展、冲突、提交和待验证项。当前实现的权威说明仍为 [architecture.md](./architecture.md)，上游协议事实仍为 [architecture-robomaster.md](./architecture-robomaster.md)。

用户已授权本目标内的代码提交，未要求推送。当前没有实机：不得把模拟应答、构建或桌面截图写成设备验证。Android 验证继续遵守项目的桌面优先要求。每项交付必须覆盖协议/业务、共享状态、实际入口、错误恢复和必要验证，不能仅添加未使用的指令常量。

不实现依赖 DJI 账号和云服务的功能，包括账号、在线激活、项目云同步、官方内容分发/客服上传；不实现 Scratch/Blockly、儿童课程、大师学院等编程教学。普通 Python 创作、自主程序、技能、自定义界面仍在范围内。固件能力限本地文件的查询、校验、安装与恢复，不增加云端下载服务。SDK 占位项、内部调试 key、当前硬件不存在的扩展不能直接变成通用产品需求。

## 状态与验收

| 状态 | 含义 |
| --- | --- |
| 待实施 | 尚未开始，保留全部原始范围 |
| 实施中 | 正在补协议证据、实现或验证，不表示完成 |
| 离线完成 | 代码、桌面入口、必要离线验证和提交完成；对应物理验证仍待进行 |
| 冲突待决策 | 与现有功能冲突；本轮保持现状，见后文决策依据 |
| 不纳入 | 用户排除，或仅内部/条件能力而非已确认用户任务 |

每项离线完成时记录提交、验证命令/结果、证据位置和设备待验内容。每个新设备功能至少验证正确报文、错误/超时、断连清理与状态归属；有持续动作时增加停止、失焦和不自动恢复验证。有 UI 的功能在桌面按横屏紧凑/中等/宽窗口验收，不以构建代替界面验证。

## 冲突记录：保持现状，留待决策

以下项目不会在能力补齐时顺带改变。新能力若会触发相同冲突，先更新本表再继续独立项目。

| ID | 官方行为与现有行为 | 本轮处理 | 后续决策所需依据 |
| --- | --- | --- | --- |
| C01 | 官方水弹 SafeMode 启用时按 `_GimbalPitch > 10f` 锁发射；当前无该锁，原生安全策略 02 两者均使用 | 冻结发射规则，不直接套遥测角度或强改默认值 | 确认俯仰坐标/正方向、偏好默认、模式切换与 UI 提示；决定是否新增可选安全模式 |
| C02 | 官方动态国家代码/终端 5G 能力；当前握手固定 JP | 冻结握手报文，不推断本机/机器人所在地区 | 确认国家码来源、原生终端标志、固件回读及信道影响 |
| C03 | 官方跟随中左摇杆前后轴调整距离；当前任意非零输入取消跟随 | 保留手动接管语义，不接距离输入替换 | 决定沿用官方输入还是独立距离操作；验证 0a:a7 子操作 2 的符号/范围/停止语义 |
| C04 | 官方原生回中、底盘跟随/位置模式；当前软件反馈回中与镜头坐标辅助 | 不替换现有运动控制，也不并行争用执行器 | 实测模式切换、限位、取消与手动接管；决定哪条路径拥有运动控制 |
| C05 | 官方断线自动后退/失目标重搜；当前停止且不自动恢复机械动作 | 保留停止策略 | 明确自主恢复是否符合产品边界；验证失联、目标丢失与操作者离开场景 |
| C06 | 官方机体/队伍颜色与原生灯效；当前灯色表达遥控状态 | 不覆盖现有状态灯 | 确定用户灯色与安全/连接/对战状态的优先级及恢复规则 |
| C07 | 官方拍录按钮操作机内 SD；当前按钮保存主机文件 | 保留原按钮目的地；A05 提供明确独立的机器人 SD 任务入口 | 决定是否统一目的地选择、双录制状态和故障提示；禁止同一按钮静默改目的地 |
| C08 | 官方机内速度等级/独立参数；当前主机五档限速 | I01 可增加查询与显式配置，不替换主机档位 | 明确机内限速与主机限速叠加含义，按实测决定是否收敛 |
| C09 | 官方扬声器读写机器人状态；当前保存应用音量并在连接时下发 | A01 增加显式回读/确认，不修改现有连接时应用偏好的策略 | 决定机器人音量与应用偏好的权威归属及多客户端操作体验 |

## 排除与条件能力

| 范围 | 处理依据 |
| --- | --- |
| DJI 账号、云同步、在线激活、官方云项目/消息/客服上传、云端固件下载 | 用户排除账号和云服务依赖；保留必要只读设备状态及本地维护 |
| Scratch/Blockly、大师学院、儿童编程课程与学习进度 | 用户排除儿童编程教学；不影响普通 Python 功能 |
| GPS/产品改进统计/官方追踪服务 | 非操控必需且依赖官方服务，不复制其数据收集 |
| 内部工具、调试开关、无消费者或占位 key | 不以 key 数量作为开发目标；先证明用户任务和有效契约 |
| 旧终端 3D Touch、无对应执行器的副相机/扩展 | 按真实平台/硬件能力判断适用性，不硬编码型号支持列表 |
